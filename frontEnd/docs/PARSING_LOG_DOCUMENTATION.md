# Complete Parsing Log Documentation

## Overview
This document describes the complete parsing log structure generated by the OCR voter data extraction system. The logs provide detailed insights into the parsing process, including extraction strategies, fallback mechanisms, and debugging information.

## Log Structure

### 1. Name Extraction Logs (`extractAllNames`)

#### Initial Extraction Phase
```
=== EXTRACTING NAMES ===
Content preview: [First 200 characters of content]...
```

#### Strategy 1: Labeled Names (Most Reliable)
```
Found labeled name: "[raw_name]" -> "[cleaned_name]"
Found [count] labeled names
```

#### Strategy 2: Unlabeled Names (If Strategy 1 fails)
```
No labeled names found, trying unlabeled extraction...
Found unlabeled name: "[raw_name]" -> "[cleaned_name]"
Found [count] unlabeled names
```

#### Strategy 3: Permissive Extraction (If Strategy 2 fails)
```
Still no names found, trying permissive extraction...
Found permissive name: "[raw_name]" -> "[cleaned_name]"
```

#### Strategy 4: Aggressive Fallback (If Strategy 3 fails)
```
No names found with standard patterns, trying aggressive fallback...
Found aggressive name: "[raw_name]" -> "[cleaned_name]"
Found [count] aggressive names
```

#### Strategy 5: Segment-based Extraction (If Strategy 4 fails)
```
No names found with patterns, trying segment-based extraction...
Found segment name: "[raw_name]" -> "[cleaned_name]"
```

#### Strategy 6: Truncated Names and OCR Artifacts
```
Checking for truncated names and OCR artifacts...
Found truncated name: "[potential_name]"
```

#### Strategy 7: Final Desperate Attempt (If all strategies fail)
```
No names found with any strategy, trying final desperate attempt...
Found desperate name: "[potential_name]" -> "[cleaned_name]"
```

#### Name Sorting and Final Results
```
Sorting names by position in content...
Original order: [array_of_names]
Sorted order: [sorted_array_of_names]
Final name count: [count]
Names found: [array_of_names]
=== END NAME EXTRACTION ===
```

### 2. House Number Extraction Logs (`extractAllHouses`)

#### Main Pattern Extraction
```
Found [count] houses: [array_of_house_numbers]
```

#### Fallback Pattern (If main pattern fails)
```
No houses found with main pattern, trying fallback...
Raw house number: "[raw_house_number]"
Extracted house number: "[raw_house_number]" -> "[cleaned_house_number]"
Skipping malformed house number: "[malformed_house_number]"
```

### 3. Age and Gender Extraction Logs (`extractAllAgesAndGenders`)

#### Main Pattern Extraction
```
Found age/gender: age="[age]", raw="[raw_gender]" -> clean="[clean_gender]" -> marathi="[marathi_gender]" english="[english_gender]"
```

#### Fallback Pattern (If main pattern fails)
```
No age/gender pairs found with main pattern, trying fallback...
```

#### Page Ending Fallback (If still no results)
```
Still no age/gender pairs found, trying page ending fallback...
Found page ending age/gender: age="[age]", raw="[raw_gender]" -> clean="[clean_gender]" -> marathi="[marathi_gender]" english="[english_gender]"
```

### 4. Row Processing Logs (`parseVoters`)

#### Row Analysis
```
=== Row with [header_count] headers ===
Headers: [array_of_header_info]
Names found: [count] [array_of_names]
Relations found: [count] [array_of_relations]
Houses found: [count] [array_of_houses]
Ages/Genders found: [count] [array_of_age_gender_objects]
Content preview: [first_200_characters]...
```

#### House Number Debugging (If no houses found)
```
No houses found! Looking for house number patterns in content...
House number matches found: [array_of_matches]
```

#### Voter Matching Process
```
=== MATCHING VOTERS FOR ROW ===
Headers count: [count]
Names count: [count]
Names: [array_of_names]
Relations count: [count]
Relations: [array_of_relations]
```

#### Individual Voter Processing
```
--- Processing voter [voter_number] (Serial: [serial_number]) ---
Initial name from array[[index]]: "[name]"
```

#### Name Recovery Strategies (If name is missing)
```
Looking for name near serial [serial_number]...
Found name near serial [serial_number]: "[raw_name]" -> "[cleaned_name]"
Inferred missing name from relation: "[relation_name]"
Found nearby name for missing voter: "[potential_name]"
Reconstructed truncated name: "[potential_name]"
Trying to find unused name for voter [serial_number]...
Found unused name: "[unused_name]"
No name found for voter [serial_number] - marking as missing
```

#### Final Voter Results
```
Final name for voter [serial_number]: "[final_name]"
Voter [serial_number]: [final_name] or [MISSING NAME]
```

## Log Patterns and Regular Expressions

### Name Extraction Patterns
- **Labeled Pattern**: `मतदाराचे पूर्ण\s*[;:]\s*([^:]+?)(?=\s*(?:मतदाराचे पूर्ण|पतीचे नाव|वडिलांचे नाव|घर क्रमांक|वय|लिंग|\d{1,4}\s+[A-Z]{2,}[0-9]{5,}|$))`
- **Unlabeled Pattern**: `([अ-ह]{2,}(?:\s+[अ-ह]{2,}){0,4})\s+(?=(?:पतीचे नाव|वडिलांचे नाव|घर क्रमांक|वय|लिंग|\d{1,4}\s+[A-Z]{2,}[0-9]{5,}|$))`
- **Permissive Pattern**: `([अ-ह]{2,}(?:\s+[अ-ह]{2,}){1,3})(?=\s*(?:पतीचे|वडिलांचे|घर|वय|लिंग|Photo|Available|नांव|\d{1,4}\s+[A-Z]{2,}|$))`

### House Number Patterns
- **Main Pattern**: `घर क्रमांक\s*:?\s*([०-९0-9]+)(?=\s+(?:घर क्रमांक|वय|लिंग|मतदाराचे पूर्ण:|\d{1,4}\s+[A-Z]{2,}[0-9]{5,}|$))`
- **Fallback Pattern**: `घर क्रमांक\s*:?\s*([^\s]+)`

### Age and Gender Patterns
- **Main Pattern**: `वय\s*:\s*([०-९0-9]+)\s+लि[ंं]?ग\s*:\s*([^\s]+?)(?=\s+(?:वय|मतदाराचे पूर्ण:|\d{1,4}\s+[A-Z]{2,}[0-9]{5,}|\*.*DELETED.*|$))`
- **Gender Pattern**: `(स्त्री|महिला|पु|पुरुष|स्त्रि|स्त्र|पू|पुः)`
- **Age Pattern**: `वय\s*:\s*([०-९0-9]+)`

## Data Cleaning Operations

### Name Cleaning
- Remove noise words: `नांव`, `Photo`, `Available`, `Phot`, `पांव`, `तांव`, `गांव`
- Normalize whitespace: Replace multiple spaces with single space
- Trim leading/trailing whitespace

### Gender Normalization
- Fix OCR variations: `पू` → `पु`
- Normalize anusvara: `ंं` → `ं`
- Map to standard forms:
  - Female: `स्त्री`, `महिला`, `स्त्रि`, `स्त्र` → `स्त्री`
  - Male: `पु`, `पुरुष`, `पू`, `पुः` → `पु`

### Number Conversion
- Convert Devanagari numerals to ASCII: `०-९` → `0-9`

## Error Handling and Fallback Strategies

### Name Extraction Fallbacks
1. **Strategy 1**: Labeled names with "मतदाराचे पूर्ण:" prefix
2. **Strategy 2**: Unlabeled Marathi text patterns
3. **Strategy 3**: Permissive extraction with relaxed constraints
4. **Strategy 4**: Aggressive fallback with broader patterns
5. **Strategy 5**: Segment-based extraction by splitting content
6. **Strategy 6**: Truncated names and OCR artifacts
7. **Strategy 7**: Final desperate attempt with any Marathi text

### House Number Fallbacks
1. **Main Pattern**: Standard "घर क्रमांक" format
2. **Fallback Pattern**: More permissive pattern for malformed data
3. **Numeric Extraction**: Extract only numeric parts from malformed data

### Age/Gender Fallbacks
1. **Main Pattern**: Standard "वय: X लिंग: Y" format
2. **Separate Extraction**: Extract ages and genders separately
3. **Page Ending**: Handle truncated data at page endings

## Log Analysis Utilities

### Key Metrics to Track
- **Extraction Success Rate**: Percentage of successful extractions per strategy
- **Fallback Usage**: How often each fallback strategy is used
- **Data Quality**: Number of missing or malformed fields
- **Processing Time**: Time taken for each extraction phase

### Common Issues and Solutions
- **Missing Names**: Use relation names or nearby text patterns
- **Malformed House Numbers**: Extract numeric parts only
- **OCR Gender Errors**: Normalize common OCR variations
- **Truncated Data**: Use page ending patterns
